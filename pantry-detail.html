Pantry Web App

HTML5 CSS3 JavaScript

Project Overview

A dynamic and highly responsive web application designed to manage household kitchen inventories. It helps prevent food waste by keeping a clean record of your pantry stock, calculating budgets dynamically, and tracking product lifespans.

Key Features

  • Barcode Scanning: Integrated local script logic to capture and log product codes swiftly using devices.
  • Dynamic Grocery List: Calculates estimated budgets in real-time as items are ticked off.
  • Smart Expiry Alerts: Highlights items approaching their best-before dates with custom UI indicators.
